# SSS Pen (Windows) — рисование поверх экрана + скриншоты как в Lightshot

## Запуск
1. Установи .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. В папке проекта: `dotnet run`
3. Готовый exe: `dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true`
   (появится в `bin/Release/net8.0-windows/win-x64/publish/`)

## Панель
- Левый клик по иконке в трее — показать/скрыть панель (или Ctrl+Alt+Q).
- Инструменты на панели постоянные: выбрал и рисуешь, пока не нажмёшь «курсор».
- Панель можно таскать за верхнюю полоску. Размер — в настройках.

## Хоткеи по умолчанию (меняются в настройках)
| Действие | Сочетание |
|---|---|
| Перо вкл/выкл | Ctrl+Alt+E |
| Быстрая линия / прямоугольник / эллипс / стрелка (одна фигура → обратно на курсор) | Ctrl+Alt+W / R / D / A |
| Ластик (постоянный, выключается пером Ctrl+Alt+E) | Ctrl+Alt+X |
| Отменить / Очистить | Ctrl+Alt+Z / Ctrl+Alt+C |
| Цвета 1-6 | Ctrl+Alt+1 … 6 |
| Панель показать/скрыть | Ctrl+Alt+Q |
| Скриншот всего экрана (монитор под курсором) | Ctrl+Alt+Home |
| Скриншот области | Ctrl+Home |
| Настройки | Ctrl+Alt+S |

## Скриншот области (как Lightshot)
Выдели область мышью. Потянув за маркеры по краям, меняешь размер (размер в пикселях пишется над рамкой).
Без выбранного инструмента область можно перетаскивать. Инструменты — карандаш, линия, стрелка, прямоугольник, эллипс.
- Ctrl+S — сохранить в папку для областей, Ctrl+C — в буфер обмена, Ctrl+Z — отмена, Esc — закрыть.

Папки по умолчанию: обычные скриншоты — `Изображения\SSSPen`, области — `Изображения\SSSPen\captures` (меняется в настройках).
Все остальные настройки: окно настроек. Файл настроек: `%AppData%\SSSPen\settings.json`
